# Desktop icon source

The application icon is derived from the Windrun site favicon:

- Source: https://windrun.io/favicon.ico
- Site: https://windrun.io
- Retrieved: 2026-07-21
- Generator: `tauri icon`

`source/windrun-favicon.ico` is the downloaded source file. The PNG, ICO and ICNS
files in this directory are generated Windows/macOS desktop bundle assets. Mobile
icon outputs are intentionally not included because the project targets desktop
Windows and macOS only. Re-check the source site's permission and branding terms
before public redistribution.
